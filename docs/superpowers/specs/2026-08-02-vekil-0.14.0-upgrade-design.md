# Vekil v0.14.0 Upgrade Design

## Outcome

Upgrade the repository-managed Vekil installation from v0.13.3 to v0.14.0 so
Codex remote compaction uses Vekil's proxy-owned 16,384-token output allowance.
Keep the existing installer, lifecycle, and authentication behavior unchanged.
Adapt the managed Claude environment to v0.14.0's native Copilot Messages route
without affecting direct Claude API sessions.

## Evidence

- The installed v0.13.3 proxy repeatedly returned `502 Bad Gateway` for Codex
  remote compaction while logging `upstream summary response contained no output
  text`.
- The failure occurred on `gpt-5.6-sol` while ordinary Responses requests
  continued to succeed, ruling out general connectivity and authentication.
- Upstream Vekil PR #269, released in v0.14.0, changed internal compaction to set
  proxy-owned `max_output_tokens: 16384` instead of leaving the upstream default
  after removing caller limits.
- An isolated v0.14.0 server successfully compacted the captured failed-session
  replay: 213,141 input tokens, 4,380 output tokens, HTTP 200, and a valid
  compaction checkpoint.
- A managed v0.14.0 runtime returned HTTP 400 for Claude Code requests carrying
  `Anthropic-Beta: advisor-tool-2026-03-01`; rolling the runtime back to v0.13.3
  immediately restored HTTP 200 Claude responses.
- Upstream v0.14.0 commit `c085fe7` sends catalog-advertised Copilot Claude
  models through native `/v1/messages`, preserving Anthropic beta headers that
  v0.13.3's Chat translation path did not forward.
- Vekil's v0.14.0 client documentation and live smoke test both require
  `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` because Copilot does not accept the
  Advisor Tool beta header.

## Changes

Update the canonical Vekil version, release URL, and four platform digests in
`config/versions.env`. Update dependency-pin test fixtures and assertions that
intentionally encode the current release.

When `ai/vekil/env.zsh` manages the Anthropic proxy endpoint, also set
`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` and record that the value is Vekil-managed.
Follow the existing ownership pattern used for the managed endpoint, key, and
model variables:

- Preserve an explicit user value rather than claiming ownership of it.
- Remove only a value that is still equal to the Vekil-managed value when the
  proxy becomes unavailable or the user replaces it.
- Make `claude-direct` unset the managed compatibility value together with the
  managed proxy variables, so a direct Claude API session can use Advisor Tool.
- Leave a user-owned value intact in `claude-direct`.

This option is narrower than exporting the variable globally, which would also
disable Advisor Tool for direct Anthropic sessions. Filtering the header in the
dotfiles proxy launcher was rejected because the proxy binary owns request
translation and the repository should not wrap or patch upstream protocol
behavior.

The official GitHub release asset digests are:

- Darwin AMD64: `45ddf66c317c687b7b1830ac4def0b1056aa78e539f5d79a0b80e3334549591d`
- Darwin ARM64: `22b66df66283161370dc348c5f270ccf503f51b9475cc20675e418fe5830fd61`
- Linux AMD64: `42f956b860eb3c3f2a1a88496e0032e89161d837d22f8c9bfa3643743e4c2461`
- Linux ARM64: `a2eee88d210f904d4170cd0e180a8b7f2fd3bec548a3218d8040f22ce5c4dcbc`

## Verification

1. Change the dependency-pin expectations first and observe their focused test
   fail against v0.13.3.
2. Update the canonical pin and observe the focused test pass.
3. Run installer tests, pin checks, and the repository's full validation gate.
4. Add shell tests first for proxy-scoped Advisor Tool disabling, user override
   preservation, convergence cleanup, and `claude-direct`; observe them fail,
   then update `env.zsh` and its operational documentation.
5. Start v0.14.0 on an isolated non-default port and verify both the captured
   compaction replay and a Claude Code smoke request with the managed
   compatibility environment before changing the live runtime.
6. Install through `ai/vekil/install.sh`, confirm the managed version and service
   readiness, and confirm a live Claude request succeeds.
7. Confirm the final diff contains only the approved pin, release-coupled
   fixtures, shell compatibility behavior and tests, and design/plan
   documentation.

## Exclusions

- No speculative semantic-empty retry in Vekil upstream; current upstream
  already contains the released fix that addresses the observed version gap.
- No Codex model, reasoning-effort, or proxy endpoint changes.
- No changes to Vekil credentials, persisted sessions, or lifecycle ownership.
- No permanent disabling of Claude Advisor Tool outside Vekil-managed sessions.
- No second live-runtime v0.14.0 installation until both isolated protocol
  checks pass.
