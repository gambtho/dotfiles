# Vekil v0.14.0 Upgrade Design

## Outcome

Upgrade the repository-managed Vekil installation from v0.13.3 to v0.14.0 so
Codex remote compaction uses Vekil's proxy-owned 16,384-token output allowance.
Keep the existing installer, lifecycle, authentication, and client configuration
unchanged.

## Evidence

- The installed v0.13.3 proxy repeatedly returned `502 Bad Gateway` for Codex
  remote compaction while logging `upstream summary response contained no output
  text`.
- The failure occurred on `gpt-5.6-sol` while ordinary Responses requests
  continued to succeed, ruling out general connectivity and authentication.
- Upstream Vekil PR #269, released in v0.14.0, changed internal compaction to set
  proxy-owned `max_output_tokens: 16384` instead of leaving the upstream default
  after removing caller limits.
- An isolated v0.14.0 server successfully compacted the captured failed-session
  replay: 213,141 input tokens, 4,380 output tokens, HTTP 200, and a valid
  compaction checkpoint.

## Changes

Update the canonical Vekil version, release URL, and four platform digests in
`config/versions.env`. Update dependency-pin test fixtures and assertions that
intentionally encode the current release. Do not change installer or proxy
lifecycle behavior.

The official GitHub release asset digests are:

- Darwin AMD64: `45ddf66c317c687b7b1830ac4def0b1056aa78e539f5d79a0b80e3334549591d`
- Darwin ARM64: `22b66df66283161370dc348c5f270ccf503f51b9475cc20675e418fe5830fd61`
- Linux AMD64: `42f956b860eb3c3f2a1a88496e0032e89161d837d22f8c9bfa3643743e4c2461`
- Linux ARM64: `a2eee88d210f904d4170cd0e180a8b7f2fd3bec548a3218d8040f22ce5c4dcbc`

## Verification

1. Change the dependency-pin expectations first and observe their focused test
   fail against v0.13.3.
2. Update the canonical pin and observe the focused test pass.
3. Run installer tests, pin checks, and the repository's full validation gate.
4. Install through `ai/vekil/install.sh`, confirm the managed version and service
   readiness, then replay the captured production-sized compaction request.
5. Confirm the final diff contains only the version/digest/test updates and this
   design/plan documentation.

## Exclusions

- No speculative semantic-empty retry in Vekil upstream; current upstream
  already contains the released fix that addresses the observed version gap.
- No Codex model, reasoning-effort, or proxy endpoint changes.
- No changes to Vekil credentials, persisted sessions, or lifecycle ownership.
